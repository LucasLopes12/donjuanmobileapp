## 🚀 Features
- Barbers Marketplace — listagem de barbearias com informações de preço, avaliação e logo.

- Organização limpa — projeto estruturado usando assets, componentes e styles separados.

- Header fixo — navegação simples, direta e visualmente consistente.

- Pronto para expansão — estrutura preparada para adicionar API, filtros, autenticação ou banco de dados futuramente.

## ⚡ Quick Start

    # Clonar o repositório

    git clone https://github.com/LucasLopes12/donjuanmobbileapp

    # Acessar o projeto

    cd donjuanmobileapp

    # Instalar as dependências 

    npm install

    # Iniciar o servidor Expo

    npx expo start
